# PUtils Homebrew tap

Private Homebrew formulae for PUtils commands.

```
brew install putils/tap/switch
```

Both this tap and the tools are private: Homebrew clones them over HTTPS with
your GitHub login, so `gh auth login` (with `gh auth setup-git`) must be done.

| Formula | Command |
|---|---|
| `switch` | [`sw`](https://github.com/PUtils/switch): switch the shell into a Debian 13 (or other OS) profile |
